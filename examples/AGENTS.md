# AGENTS.md — このVaultで作業するAI共通のルール

Claude Code・Cursorなど、どのAIもこのファイルのルールに従う。

## このVaultは何か

- 自分用のメモ置き場。AIごとに分けず、情報の役割でフォルダを分けている。
- コード・node_modules・ビルド成果物は入れない（コードは各案件リポジトリにある）。
- **パスワード・APIキー・秘密鍵・トークンは絶対に書かない。** 必要なら「どこに保管してあるか」だけ書く。

## どこに何を保存するか

| フォルダ | 入れるもの |
|---|---|
| `00_Inbox/` | 行き先が決まっていないメモ。迷ったらここ |
| `10_Projects/` | 案件ごとのメモ。`クライアント名/案件名.md`（デスクトップの `Web制作案件\クライアント名\案件名` と同じ名前にする） |
| `20_Knowledge/私について/` | ユーザー自身のこと（仕事・好み・判断基準・人・道具）。要約は直下の `MEMORY.md` |
| `20_Knowledge/coding-rules/` | Cursor ruleの**正本**（.md） |
| `20_Knowledge/スキル一覧/` | AIスキルの説明（何ができるか・いつ使うか・呼び出し方・手順） |
| `20_Knowledge/文体/` | `NG表現.md`（避ける言い回し）・`良い表現.md`（使う言い回し） |
| `30_References/` | 外部資料。**AIは読むだけ。書き換え・移動・削除しない** |
| `80_AI_Logs/` | AIの作業記録・引き継ぎメモ。`audit/` は改善提案レポート |
| `90_Archive/` | 使わなくなったメモ。消さずにここへ移す |

## coding-rules の扱い

- `20_Knowledge/coding-rules/*.md` が正本。テンプレートリポジトリの `.cursor/rules/*.mdc` へは書き出しスクリプトで**一方通行**に反映する。
- 各案件リポジトリの `.cursor/rules/` は直接編集しない。
- 先頭の frontmatter（`description` / `globs` / `alwaysApply`）は Cursor 用の書き方のまま残す。Obsidian のプロパティ画面では編集しない（書き方が変わって Cursor での効き方が変わるおそれがある）。
- テンプレートへの書き出しは、ユーザーが「テンプレートに書き出して」と明示したときだけ行う。

## 書き方

- 日本語で、短く、専門用語を減らす。
- `20_Knowledge/文体/NG表現.md` にある言い回しは使わない。`良い表現.md` を優先する。
- 推測で事実を書かない。わからないことは「まだわからないこと」に書き、聞けるときに質問する。

## ユーザーについて自動で保存する

ユーザーに言われなくても、会話の中でわかった**長く使える情報**は、その場で Vault に保存する。

- 保存するもの：好み・仕事の進め方・判断の基準・決めたこと・仕事や経歴・関わる人・使う道具・「次から〇〇して」「〇〇はやめて」という指示
- 保存先：`20_Knowledge/私について/` の該当ファイル（仕事と経歴／好みと進め方／判断基準と決めたこと／関わる人／道具と環境）。要点が変わったら `MEMORY.md` の要約も直す。言い回しの指示は `20_Knowledge/文体/`、案件のことは `10_Projects/`
- 書き方：同じ話題は追記せず、その箇所を書き換えて整理する。日付が大事なものは日付を添える
- 保存したら、返事の最後に「保存：〇〇（ファイル名）」と1行だけ書く。ユーザーが「それ違う」と言ったら直すか消す
- 書かないもの：推測（本人が言ったこと・行動から確実なことだけ）、パスワード・キー・トークン、顧客や他人の個人情報（連絡先など）、その場限りの気分や一時的な作業メモ
- Claude Code の自動メモリ（`~/.claude/projects/.../memory/`）に保存したときも、ユーザー自身に関わる内容は Vault にも保存する。**Vault が正本**

## 作業の最後に

**まとまった作業**を終えるときだけ、`80_AI_Logs/` に引き継ぎメモを1つ書く。

- 書く：何かを決めた、ファイルを作った・直した、次回に続きがある、などの作業
- 書かない：ちょっとした質問・調べもの・雑談だけで終わったとき

- ファイル名：`YYYY-MM-DD_内容.md`（例：`2026-10-11_rule整理.md`）
- 書くこと：やったこと / 決まったこと / 残っていること / 次にやること
- 同じ日の同じ作業なら、新しく作らず追記する。
