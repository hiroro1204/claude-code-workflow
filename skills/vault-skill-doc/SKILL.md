スキルの使い方を忘れないよう、Vault にスキルごとの解説ノートを残すのが仕事。

## 保存先
- Vault：`~/Desktop/Obsidian`
- ノート：`20_Knowledge/スキル一覧/<スキル名>.md`（1スキル1ファイル。スキル名はフォルダ名・コマンド名と同じ）
- 目次：`20_Knowledge/スキル一覧/00_一覧.md`
- 書き方の見本：`20_Knowledge/スキル一覧/_テンプレート.md`

## 手順
1. 対象スキルの本体を読む
   - `~/.claude/skills/<名前>/SKILL.md`（同じフォルダの references/・scripts/ も一覧だけ見る）
   - スラッシュコマンドなら `~/.claude/commands/<名前>.md`
2. ノートがあるか確認する
   - 無い → `_テンプレート.md` の形で新しく作る
   - ある → 本体と食い違う箇所だけ直す。ユーザーが手で書き足した部分（「メモ」など）は消さない
3. 次の項目を埋める。本体に書いてあることだけを書き、推測で足さない
   - frontmatter：name / 種類（自作・外部）/ 使える場所 / 本体 / 呼び出し / 更新日（今日）
   - 何ができるか（1〜3行）
   - いつ使うか（きっかけの言葉・場面。向かない場面もあれば書く）
   - 呼び出し方
   - 手順（中の仕組み）：本体の手順を短い番号付きリストに要約
   - 守ること・注意
   - 関連ファイル
4. `00_一覧.md` の表に1行追加、または既存の行を更新する
5. 「スキル一覧を更新：<名前>（新規 / 更新）」と1行だけ報告する

## 守ること
- パスワード・APIキー・トークン・接続情報の値は書かない。環境変数名や「どこに保管しているか」だけ書く
- スプレッドシートの ID や顧客の個人情報など、本体にあっても Vault に不要な細かい値は書かない
- 説明は日本語で短く、専門用語を減らす
- 本体（SKILL.md）は変更しない。このスキルが書くのは Vault のノートだけ
- `~/.claude/skills/synced/` 配下（claude.ai から同期されるもの）は対象外
- 同じ作業の中で本体が何度も編集された場合、ノートの更新は最後に1回でよい
